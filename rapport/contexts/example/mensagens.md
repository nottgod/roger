# Ledgerline — message templates

**Fictional example.** The engine reads the **first block quote** under each heading, so keep
that shape: one heading per template, the text quoted with `>` underneath.

These are skeletons, not messages to send as they are. `{Nome}` is replaced with the lead's
first name; anything else in braces is a note to you, and the voice guard will block it if it
ever reaches a real message.

## M1 — handshake (campaign only, no pitch)

> Great to connect, {Nome}! I'll write to you shortly with some context on why I reached out.

Short on purpose. No pitch, no question, nothing to answer. It exists so the second message
arrives in a thread that already exists.

## M2 — the pitch, same thread

> {Nome}, as promised, some context. We replace the spreadsheet your finance team maintains by
> hand at month close, so the number is right on the first try. Worth a quick call this week to
> see if that fits how you close?

## M2-direto — first touch with no campaign

> {Nome}, {one specific line about them}. We replace the manual part of month close for finance
> teams at {their kind of company}. Open to a quick call this week?

## Notes

- One question per message. Two questions means neither gets answered.
- The hook has to prove you looked. If you cannot find one, the lead is not ready to write to.
- Never invent a number about them. If you do not know their volume, do not guess it.
